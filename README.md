# 天鲜账本 V1.1.6

## 本版更新
- APP 名称改为：天鲜账本
- 启动图标改为你提供的蓝宝石葡萄品牌图标
- AndroidManifest 增加 `android:icon` 与 `android:roundIcon`
- 新增多分辨率 launcher 图标资源：mdpi / hdpi / xhdpi / xxhdpi / xxxhdpi

## 保留
- 继承 V1.1.5 的全部功能与修复
  - 营业记录支持编辑
  - 进货记录支持编辑
  - 删除合伙人后历史记录仍可编辑
  - 已删除摊位的历史营业记录仍可编辑

- versionName: 1.1.6
