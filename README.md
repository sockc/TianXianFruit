# 天鲜果业经营助手 V1.1.3

包名：`com.tianxian.fruit`

## V1.1.3
- 进货录入单位默认改为「件」。
- 进货历史支持编辑整张进货单：
  - 日期
  - 进货人
  - 水果明细
  - 单位
  - 数量
  - 总价
  - 备注
- 保留批量进货与删除。
- 修复 V1.1.2 营业记录保存时摊位可能被错误写为“共用货品”的问题。
- 营业费用增加“费用付款人”，用于当天资金结算。
- 新增真正的「当日资金结算」：
  - 读取每人进货垫付
  - 读取每人费用垫付
  - 读取每人实际收款
  - 读取独立利润分配表的应得利润
  - 自动计算每个人应收 / 应转出
  - 自动生成尽量少的转账方案
  - 支持确认“今日已结清”
  - 支持删除结算历史
- 当开摊库存与收摊库存不同，系统会阻止现金结清并提示核对，避免把库存价值当成现金分掉。
- 数据库升级到 v4，旧数据保留。

## 重要
V1.1.2 曾有一个摊位保存字段错误。
如果你已经用 V1.1.2 保存过营业记录，且历史里显示成“共用货品”，该条记录无法自动判断原来选择的是哪个摊位，请删除后重新录入。

## 签名
继续使用原来的：
- SIGNING_KEY_BASE64
- KEYSTORE_PASSWORD
- KEY_ALIAS

不要更换 keystore。
