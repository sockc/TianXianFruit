# 天鲜果业经营助手 V1.1.2

包名：`com.tianxian.fruit`

## 本版重点
- 首页重做为品牌化 Dashboard：绿色品牌头、日期/摊位、四宫格核心指标、快捷操作、7天营业额趋势、常用功能。
- 进货表取消“供货摊位”，所有进货视为共用货品。
- 进货日期 + 进货人同一行。
- 进货支持批量增加商品，数量/总价/单价输入区域缩小。
- 进货历史继续支持删除。
- 营业表“摊位 + 收款归属”同一行。
- 微信/支付宝/现金、费用、库存、客户输入框改为更紧凑的自定义小输入框。
- 营业页只保留一个收款归属。
- 合伙人不限人数、支持改名/删除。
- 利润分配独立、百分比自定义、历史支持删除。
- 共用进货不再硬归属某个摊位；每日总利润统一扣除全部进货。
- 摊位利润排行榜为了可比较，将当天共用进货按各摊位营业额比例分摊（仅用于排行）。
