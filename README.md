# 天鲜账本 V1.2.0 Phase5.1

## 进货动态商品行
每一种水果直接保留在页面中：

第一行：
水果 / 单位

第二行：
数量 / 总价 / 单件

点击“添加商品”，在下方增加下一组同样的输入框。
全部录入后统一保存整张进货单。

## 历史时间筛选
更多 → 历史记录支持：
全部、今天、昨天、近7天、近30天、本月、上月、自定义起止日期。

筛选范围统一作用于营业、进货、利润分配和采购计划历史。

## 版本
- versionCode: 13
- versionName: 1.2.0
- DB_VERSION: 6

## 签名
继续使用原来的：
- SIGNING_KEY_BASE64
- KEYSTORE_PASSWORD
- KEY_ALIAS

不要更换 keystore。

## V1.2.1 界面优化

- 首页、进货、营业、结算支持左右箭头切换前后一天。
- 首页日期可点击选择历史日期。
- 最近7天营业额趋势增加每日营业额数字。
- 更多页面将历史记录和经营统计合并为数据中心。
- 更多页面去掉功能卡片说明文字。
- 水果商品管理改名为商品管理。
- DB_VERSION 仍为 6。


## V1.2.2 经营分析与利润结算

- 经营分析支持全部/今天/昨天/近7天/近30天/本月/上月/自定义时间筛选。
- 结算拆分为当日结算、批量结算、结算统计。
- 每位合伙人每天的利润可独立确认是否已结算。
- 支持3～7天或任意范围批量选择合伙人统一结算。
- 结算统计显示应得、已结算、待结算、每日明细和期间合计。
- 新增结算批次，可撤销误确认。
- DB_VERSION 7。

## V1.2.3 报表功能

- 更多 → 生成报表。
- 支持利润分配、利润结算、经营汇总三类报表。
- 支持时间筛选、合伙人筛选、简洁版/详细版。
- 支持生成 PDF、PNG，并通过 Android 系统分享面板分享。
- 支持另存为 PDF / PNG。
- DB_VERSION 保持 7。
