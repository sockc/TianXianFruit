# 天鲜果业经营助手 V1.1.5

## 核心修复
V1.1.5 解决“删除合伙人后营业表/进货历史无法继续编辑保存”的问题。

- 新建营业、进货：只能选择当前有效合伙人。
- 已删除合伙人不再出现在新记录下拉框。
- 历史营业引用已删除合伙人时显示“姓名（已删除）”。
- 不主动更换归属时，可正常修改营业额、客户、库存等并保存。
- 如果主动更换收款人/费用付款人，只能换成当前有效合伙人。
- 历史进货同样支持已删除的原进货人。
- 删除合伙人不会删除历史进货、营业、利润分配、资金结算。
- 同样修复已删除摊位的历史营业编辑：旧摊位显示“摊位名（已删除）”，保留原历史引用。
- 保留 V1.1.4 的营业编辑、进货编辑、默认单位“件”等功能。
