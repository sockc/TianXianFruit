# 天鲜账本 V1.2.0 Phase5.1

## 进货动态商品行
每一种水果直接保留在页面中：

第一行：
水果 / 单位

第二行：
数量 / 总价 / 单件

点击“添加商品”，在下方增加下一组同样的输入框。
全部录入后统一保存整张进货单。

## 历史时间筛选
更多 → 历史记录支持：
全部、今天、昨天、近7天、近30天、本月、上月、自定义起止日期。

筛选范围统一作用于营业、进货、利润分配和采购计划历史。
