# 天鲜果业经营助手 V1.1.4

包名：`com.tianxian.fruit`

## 本版专注修复

### 营业记录支持编辑
在“营业 → 当天已记录摊位”中增加：
- 编辑
- 删除

编辑会回填：
- 日期
- 摊位
- 收款归属
- 微信
- 支付宝
- 现金
- 日常开销
- 费用付款人
- 开摊库存
- 收摊库存
- 新客
- 老客

### 修复修改利润分配后营业保存异常
- 保存瞬间重新从 SQLite 获取摊位/合伙人，不使用可能失效的页面缓存对象。
- 营业数据是源数据，利润分配/资金结算属于派生数据；派生数据不再阻止营业保存。
- 如果修改营业额、费用、库存等影响利润的字段：
  - 营业修改照常保存；
  - 当天旧利润分配自动作废；
  - 当天旧资金结算自动作废；
  - APP 提示重新生成。
- 如果只修改收款归属/费用付款人：
  - 利润分配保留；
  - 旧资金结算自动作废。

### 修复删除后不能重新保存同一日期/摊位
`store_daily_record` 有 `UNIQUE(date, store_id)`。
旧版软删除后再新增相同日期/摊位可能撞唯一约束。
本版会自动复用被软删除的旧行并恢复，不再静默保存失败。

### 利润分配规则
本版不改利润比例逻辑。
