# 天鲜账本 V1.2.0 Phase5

## 本版完成

### 采购清单：单商品独立状态
每个采购商品都有自己的状态：
- 待采购
- 已采购
- 已取消

操作：
- 待采购 → 完成 / 取消
- 已采购 → 恢复待采购
- 已取消 → 恢复待采购

首页“明日采购”显示：
- 待采购数量
- 已采购数量
- 取消数量

数据库升级：
- DB_VERSION 6
- purchase_plan_item.status
- 老数据升级后默认 status=0（待采购）

### 进货页面改成连续添加商品
操作顺序：
1. 选择水果
2. 填写数量
3. 填写总价
4. 点击“添加商品”
5. 商品立即显示在本次进货列表
6. 输入区自动清空
7. 继续选择下一种水果
8. 最后点击“保存整张进货单”

日期和进货人不会因为添加商品而清空。

本次进货临时商品支持：
- 编辑
- 删除

只有最后点击“保存整张进货单”才写入进货数据库。

### 从采购计划导入进货
进货日期存在采购计划时：
- 只导入“已采购”的商品
- 待采购和已取消商品不会导入
- 导入数量和单位
- 实际总价需要在进货列表中点击“编辑”填写
- 未填写总价时禁止保存整张进货单

### 营业编辑 Bug 修复
营业记录点击“保存修改”成功后：
- 自动退出编辑模式
- 不再继续显示“正在编辑营业记录 #...”
