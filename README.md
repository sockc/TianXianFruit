# 天鲜果业经营助手 V1.1.1

包名：`com.tianxian.fruit`  
数据库版本：`3`  
APK版本：`1.1.1`（versionCode 3）

## V1.1.1 功能

- 进货使用“进货单 + 多商品明细”，支持一次批量录入多个水果。
- 进货历史支持删除；采用软删除，方便未来云同步。
- 摆摊位置支持新增、删除；删除不破坏历史营业/进货记录。
- 合伙人数量不设上限，支持新增、改名、删除。
- 同一天可分别记录多个摊位。
- 营业页输入框改为紧凑布局。
- 一个摊位只选择一次“收款归属”，微信 / 支付宝 / 现金共用该归属。
- 每日总账继续独立汇总：营业额、各自进货、各自实际收款、费用和总利润。
- 利润分配保持独立模块，不写入营业/收款表。
- 每位有效合伙人的利润百分比可自定义，合计必须为 100%。
- 自定义百分比可保存为默认利润规则。
- 4 人且尚未设置规则时，默认给出 `33 / 13.4 / 26.8 / 26.8` 作为初始值，可直接修改。
- 当日利润分配保存后会冻结当时的姓名、比例、利润基数和分配金额。
- 利润分配历史支持按整日删除，不影响营业和总账。
- “更多”里的子页面支持系统返回键回到“更多”列表；其他底部页面按系统返回会回到 APP 首页，不再直接退出到系统桌面。
- JSON 备份包含 `profit_rule` 和 `profit_distribution`。
- 保留 `sync_id / sync_status / updated_at` 等字段，为以后云端同步预留。

## 数据库升级

数据库从 V1.1.0 的 v2 升级到 v3，只新增 `profit_rule` 表；原有业务数据不会主动删除。
包名仍为 `com.tianxian.fruit`。继续使用原固定签名即可覆盖安装并保留数据。
