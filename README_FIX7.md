# 天鲜账本 V1.4.7 FIX7

本版重构“利润什么时候可分”和“资金什么时候真的转账”的关系。

- 当日结算只做当天经营对账，不再把利润状态当成真实结算。
- 合伙人利润规则新增日结、周结（指定星期）、月结（月末）。
- 负利润自动结转抵扣未来利润，不要求当天补款。
- 资金轧差每天使用，并只纳入已到期利润；历史未结余额自动带入。
- 自动生成转账方案不等于付款，逐笔确认后才影响资金余额。
- 结算记录改为实际资金转账记录。
- 利润分配记录保存结算周期快照，后续改周期不追溯改变旧账。
