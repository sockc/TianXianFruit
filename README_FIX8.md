# 天鲜账本 V1.4.7 FIX8

## 紧急修复：当日结算资金余额恢复为当日口径

- “结算 → 当日结算”中的资金余额只显示当前所选营业日的数据。
- 不再把历史累计资金余额塞进“当日资金余额”卡片。
- 当日资金余额口径：当日采购垫付 + 当日费用垫付 + 当日到期利润 - 当日实际收款。
- 当日利润仍单独显示，日结 / 周结 / 月结规则继续保留。
- 资金轧差方案仍使用到期利润和历史未结资金生成真实转账建议，避免破坏周结 / 月结。
- “资金余额”独立页继续负责查看累计未结、历史每日余额和最终余额。
