# 联合候选 RC7 验收

Android 1.4.7.135 (173)，iOS 1.0.0 (77)，服务端 1.0.36。
线上升级及隔离 PostgreSQL 验证已由用户提供日志确认。此分支不部署服务端，不开写入开关。

## 一次集中实机核对
1. 用同一 iOS_TEST_ 账本，升级两端至候选包；先核对账本与收款人、营业、采购、库存基线。
2. 仅当有独立、已确认测试账本准入时，新增两个不同商品及位置，双向同步；核对数字 ID、sync_id、业务引用；重复名称应拒绝。当前三个新开关关闭，未获准入时本项记为阻塞而非通过。不得借正式账本测试。
3. 双端使用新商品创建测试采购、营业并盘点，核对汇总、库存、利润；用测试数据生成日结与资金余额，核对最少转账、撤销及重复请求行为。
4. 在正式账本仅核对现有历史和余额；已有授权账号的真实财务操作由用户明确决定，不生成虚假账目。检查 EDITOR 与只读成员显示及权限拒绝。
5. 检查离线/同步失败时基础编辑禁用、账本切换后权限重新核验、恢复同步后可重新授权。
6. 全部必要验收完成后才合并 main；在 main 手工运行 Build joint Android and iOS candidate 并明确选择 publish_release。两个安装包须同时通过校验，禁止覆盖已有发布。

正式账本主资料创建、合伙人改名、利润规则写入不在本次开放范围。正式 Android 结算算法无修改。
