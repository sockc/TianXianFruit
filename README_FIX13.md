# 天鲜账本 V1.4.7.13 — 资金余额 / 结算记录重构

本版基于 V1.4.7.12（V1.4.7.6 功能基线）继续优化结算表，不重新引入日结 / 周结 / 月结周期。

## 结算主线

- “最少转账方案”仍是每天最明确、最常用的资金结算入口。
- 确认最少转账方案后，真实转账金额自动进入“资金余额”和“结算记录”。
- 当天没有结清的金额继续累计到“资金余额”。
- “资金余额”不再自己建立另一套每日结算逻辑，而是作为最少转账方案执行后的扩展状态页。

## 资金余额

- 保留总览 + 合伙人卡片。
- 每位合伙人显示截至指定日期的当前未结：应收 / 应补 / 已结清。
- 自动显示“未结时间范围”和该范围包含的营业日数量。
- 自动显示最近一次余额归零的结清日期。
- 日期明细显示：当日净额、当日已执行转账、截至当日累计未结，以及采购 / 费用 / 收款 / 利润构成。
- 新增“结清截至今日”：无需设置日结 / 周结 / 月结，任何时候都可以把某位合伙人截至指定日期的累计未结一次结清。
- “结清截至今日”会生成真实 settlement_transfer 记录，并同时影响转账双方的资金余额。

## 结算记录

顶部“结算记录”改为真正的资金结算历史，不再把利润结算统计当作资金结算记录。

每次记录显示：
- 结算类型：最少转账方案 / 结清截至今日 / 旧版历史资金结算。
- 结算日。
- 时间范围（开始日期 ～ 结束日期）。
- 时间范围内包含几个营业日。
- 实际谁 → 谁、实际结算金额。
- 已结清 / 部分结算。
- 确认时间。

当天最少转账方案的时间范围固定为当天，计 1 个营业日；“结清截至今日”会记录从最近一次真正结清之后到本次截止日的未结范围。
