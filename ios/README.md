# 天鲜账本 iOS V0.6.3 · Build 40 — 资金结算表界面优化

## 本版更新
- 资金结算表采用 **每日紧凑卡片**，默认先看日期、同步状态、营业额、采购额和利润三项核心金额；点击日期卡片展开营业明细、采购、正式日结、合伙人资金、实际利润分配及转账记录。
- 日期控件与安卓及 iOS 营业/采购页面保持一致，支持左右切日、点击日历、单日/近7天/近30天/全部；位置和合伙人筛选同排，支持一键清除。
- 仅存在**唯一一份**云端正式日结快照时，卡片才显示金额；缺少快照明确标注“未同步正式日结”，发现同日多份快照则提示核对、分别展示，不求和、不用营业利润顶替日结利润。
- 盈亏以原始日结利润正负区分，负数红色显示；只读原始资金差额，不能误认为跨日可提现余额。
- 周期、资金中心转账的记录日期与覆盖营业日期分别展示，卡片显著提示，杜绝将多日资金转账错误分摊到某一日。
- 同步入口可直接刷新；在无记录、不同位置或合伙人筛选、数据未同步时均保留准确的空状态提示。
- 当日营业、采购合计只来自已保存记录；位置或合伙人筛选**只定位相关日期**，不擅自按位置拆分全账本采购成本或正式日结。
- 新增单日快照、多份快照、负利润、跨日转账、筛选归属专项单元测试。

## 安全原则
本版只修改 iOS SwiftUI 结算表及测试、版本显示。不修改安卓计算、利润分配、资金轧差、最少转账规则；不提供确认转账、已结清判断、利润重算或正式资金写入。iOS_TEST_ 既有测试账本权限不变，所有没有服务端专用事务的功能继续预留。

## 安装
GitHub Actions 产出 TianXianFruit-iOS-v0.6.3-Build40-TrollStore。iPhone X / iOS 16.6 使用 TrollStore **覆盖安装**，请勿先卸载以免丢失本机草稿与提交锁。本版不需更新服务端。
