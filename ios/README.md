# 天鲜账本 iOS V0.5.3 · Build 35 — 资金结算表（只读）

## 本版新增
- **资金结算表**：在首页快捷入口和「更多」中查看按日期归组的正式同步资金数据；原有「库存」与底部导航保持不变。
- **日期和筛选**：支持单日、近7天、近30天及全部日期，按营业位置和合伙人选择涉及的日期。
- **多位置记录**：同一天不同位置分开展示，附已保存营业额与位置利润合计；采购订单按采购日展示当日全账本合计。
- **原始结算数据**：只显示同步的 daily_cash_settlement、profit_distribution、settlement_transfer。没有正式结算快照时显式提示，绝不用营业利润推算结算结果。
- **防错误归属**：位置、合伙人筛选只用于选出匹配日期；正式结算快照及采购金额仍为全账本原值，不做位置或合伙人虚构分摊。
- **只读保护**：不生成最少转账方案、不推断已结清，不允许执行利润分配、转账、资金轧差或修改当日结算。
- **回归测试**：覆盖同日多个位置、采购日期归属、缺少快照、合伙人/位置筛选、负利润和删除同步事件。

## 安装
GitHub Actions 生成的 TrollStore IPA 可在 iPhone X / iOS 16.6 上**覆盖安装**，请勿卸载旧版以免遗失本机测试采购草稿。无需服务器新接口；资金数据由现有同步接口只读获取。

## 注意
当服务端没有同步某类结算记录时，此页显示「暂无已同步记录」，而不会用营业额计算一份假结算。正式资金和 Android 当日结算计算逻辑、UI、字段意义、转账规则维持原样。测试账本采购写入权限亦无变化。
