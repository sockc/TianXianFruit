# 天鲜账本 iOS V0.8.5 · Build 54

在 V0.8.4 的安卓 ↔ iOS 双向营业/采购同步基础上，集中优化 iPhone X 小屏幕实际录入体验与手机桌面图标。**不修改 Android 当日结算、资金轧差、分配算法，正式资金结算仍只读。**

## 本版更新
- 修复 iOS 主页面外层原生导航栏造成的白色/空白顶部，安全区域背景跟随系统浅/深色，移除重复导航标题。
- 顶部压缩为两行：天鲜果业＋同步／刷新；账本选择＋测试账本标签＋日期。保持账本切换和权限逻辑不变。
- 首页去掉第二个大标题，缩小操作卡与模块间距，使营业/采购/结算、未来天气和当日数据更早进入首屏。
- 营业：实际开摊/收摊时间靠近日期、位置；单收款人不再重复显示总计，多收款人仍保留原小计；底部固定“保存草稿/保存并同步营业”按钮，按原逻辑校验与上传。
- 采购：减少冗余说明和空白，单次连续编辑多商品，底部固定“保存采购录入/保存并准备同步”按钮，不改明细计算和原子提交流程。
- 结算：精简顶部两行标题与冗余卡片，原始日结、资金差额、转账进度、已保存合伙人利润分配均原样读取云端。
- 新增水果＋账本的 iOS AppIcon 资源集，CI 自动生成 iPhone/iPad 各尺寸 PNG，确保 `Info.plist` 中注册 `AppIcon` 并将 `Assets.car` 纳入 IPA。

## 图标说明
- 原始图标图片：`ios/Config/AppIconSource.jpg`；图标制备脚本：`ios/scripts/generate_app_icon.sh`。
- GitHub Actions 的 `macos-15` 机器使用系统 `sips` 将原始图片生成全套 AppIcon PNG；不依赖在线图像下载。
- 首次安装及更新后如 iOS 图标未立即刷新，可通过重启 SpringBoard/重新启动设备刷新桌面缓存，但**不要卸载 App**，以免清除本机草稿及不可变提交记录。

## 发布
- 当前 iOS 版本：**V0.8.5 Build 54**。
- 构建方式：`Build TrollStore IPA (no Apple certificate)`，工件 `TianXianFruit-iOS-v0.8.5-Build54-TrollStore`。
- CI 编译、测试、生成图标与打包检查全部通过后，方能确认安装包可下载。
- 继续使用已上线的 V1.0.32 原子权限与账本/用户双白名单；本次不改服务端开关，不提前开放正式资金结算。
