# 天鲜账本 iOS V0.8.3 · Build 52 — 营业、采购、结算实用版

此版以 V0.8.2 为基础，集中完成日常输入、正式账本采购准备与安全回读。

## 营业
- 正式账本获得服务端明确授权时，可恢复异常后的同一不可变营业操作，不再被旧测试账本专用入口拦截。
- 实际营业起止时间默认展开；未完整填写合法 HH:mm 时间不得正式上传。
- 逐项提示缺失的收款人、收入、支出及库存估值；允许保留不完整本机草稿，但不能将空值当零上传。
- 每日期与位置防重复，上传后只允许通过原操作编号核对/恢复，保持旧 outbox。

## 采购
- 修复正式账本采购提案仍限制 `iOS_TEST_` 的问题。正式账本只在 **scope=formal** 且功能开关/账号权限和账本完全匹配时生成提案。
- 每次提交前要求完整云端刷新、重新读取账号账本对应服务端能力；实际网络写入前后仍有服务端独立权限核验和不可变操作保护。
- 计划金额、完成计划金额、云端采购订单总额分别显示；本机草稿不计入营业/结算，金额保留完整元单位不缩写 K。
- 单一采购人默认选中。修改采购未保存就退出时明确提醒；继续原有提交确认，避免误写。
- 完整云端回读订单、商品与采购计划完成状态后才标记“云端已确认”。

## 结算
- 卡片显示 **云端当日转账原始登记** 的方案总笔数、全额登记、部分登记、未登记及异常数量，只为原始记录展示。
- 正式账本的日结、资金余额、利润分配及转账更新**仍保持只读**；绝不从这些计数推算跨日余额或最终结清状态。
- 不改 Android 当日结算算法、UI、最少转账方案和云端资金数据。

## 部署及安装
- 服务端升级至 V1.0.32 不等于正式写入自动开放。正式写入须额外配置账本 UUID + 操作人 UUID 双白名单、独立功能开关与账号权限，并经过双端回归。
- Github Actions 工件名称 `TianXianFruit-iOS-v0.8.3-Build52-TrollStore`；iPhone X/iOS 16.6 用 TrollStore **覆盖安装**，不要卸载以免丢失本机草稿。
- 原生编译、模拟器单元测试及设备 IPA 打包需全部通过后才算发布完成。
