# 天鲜账本 iOS V0.6.0 · Build 37 — 安卓风格统一操作台

## UI 与输入习惯
- 首页改为「天鲜果业 / 经营概览 / 常用操作 / 天气 / 经营指标」，补齐营业录入、采购、库存、资金结算、客户分析、经营统计快速入口；原有底部五个入口不删除。
- 营业和采购统一左右切换日、点击日期选择；采购明细保持数量/单价/单位/重量原逻辑，统一数字键盘和金额右对齐，保留安卓的商品进价、总价口径，不修改任何结算算法。
- 更多页按常用、功能预留、旧版测试工具、账号与同步组织。
- 未实现写入的库存、结算执行、利润分配、客户导入、凌晨收款和账本成员管理均预留完整可见的入口，说明目前尚不具备安全写入接口。

## 测试账本集中开放
- 仅名称以 iOS_TEST_ 开头、在线授权且有编辑权限的账本展示统一「测试账本工作台」。
- 当前已实现的营业新增、采购新增及待采购完成、营业更正和采购备注更正统一列出，不再逐项修改客户端开关。
- 登录、恢复会话、切换账本时自动查询营业和采购写入能力；操作实际提交之前继续按当前服务端能力、当前账号和账本 scope 重新核对，保证幂等及冲突保护。
- 营业更正和备注更正保留原有独立测试账号核验流程。不用旧的通用 sync/push 冒充原子写入。
- 缺少服务器事务接口的模块仍是功能预留，不直接写入；测试账本不是无条件免权限写入。

## 正式写入上线门槛
将来统一开放正式账本写入，仍需全部相关服务端事务、权限、并发、去重、跨设备回读及 Android/iOS 一致性测试通过，之后再独立审查发布。**Build 37 未开放正式账本写入，也未修改正式结算数据。**

## 安装
GitHub Actions 自动构建 TrollStore IPA，适用于 iPhone X / iOS 16.6；覆盖旧版安装，勿卸载本机草稿。无须服务器升级。
