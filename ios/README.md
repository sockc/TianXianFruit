# 天鲜账本 iOS V1.0.1 · Build 78 — 安卓 UI 对齐第一阶段

- 首页、库存、采购、营业、结算共享经营日期；中国时区、中文星期、左右滑动、整月日历及确认。未来采购日期仍可选择，切到其他经营表回到不晚于今天；更换账本或退出重置工作日期。编辑器保留原独立日期及未保存保护。
- 首页四宫格（营业额/采购金额/实际利润/预估利润），使用原库存经营分析口径；天气移到核心操作下方，历史七天随日期变化。
- 采购计划默认展开，压缩金额与状态；营业日期、标题与历史记录更紧凑，库存四摘要和五列卡片、损耗与剩余快速输入；结算模块入口前置。保留已有计算、云端写入限制、回读、草稿与自动保存。
- 采购主页面“新增采购”改为内嵌编辑；历史/计划录入仍使用原弹层，营业新增与待处理草稿改为主页面内嵌，保留原历史详情入口。内嵌录入期间阻止切换账本、日期和底部标签，取消保留未保存提示，保存后仍必须明确确认云端提交。采购总价仍为只读计算；待实机安全验收。未引入未支持的凌晨收款、账单导入、利润规则写入。
- 独立候选 IPA 构建，不自动发布正式联合 Release，不改变 Android 或服务器。iPhone X 实机布局待核对。

- 拆分库存卡片 SwiftUI 子视图，修复此前编译器类型检查超时；不更改库存数量或估值规则。

- 营业录入分为位置时间、收款、成本和提交状态等紧凑区域；未补齐成本仍可保存本机草稿，营业额预览不代表已同步收入。录入时锁定账本及底部导航，关闭/切换日期位置仍按原未保存保护流程处理；不新增凌晨扣减或费用付款人字段。

- 商品总价可点击反算单价并确认；只能在既有两位小数价格和三位小数数量规则下精确得到原实付总价。整单“总价”不反算单品；无解时拒绝而非静默舍入。采购云端算法不变。
- 客户分析压缩日期/位置/渠道/三金额指标，新增按有效收款账单分页、自定义开始日至选中日期范围、逐小时笔数/金额切换。未导入/位置未匹配/离线警示继续保留；仅展示已有云端数据，不新增账单导入或客户身份推断。

- 结算页移除重复顶部同步栏，预览、已保存日结、资金余额与历史明确分区；原始利润分配排在轧差和转账前，三金额使用紧凑色块。预览只在当前账本/日期/同步版本有效，离线或失败时隐藏。原算法、权限、操作及原始状态解释不变。
- 更多页按安卓经营数据、经营资料、账本与数据、设置分类，保留全部已有入口，底部六标签突出选中状态。不新增未支持的备份、协作采购、系统设置或分享功能。
