# 天鲜账本 iOS V0.6.2 · Build 39 — 营业表与采购表快速录入

## 当前版本更新
- **统一数字输入**：营业收款、营业支出、库存估值、采购数量/单价/规格重量改为安卓常见的“点按后全选旧值，直接输入新值”。例如默认 0 或数量 1 可直接覆盖，不再需要长按清空。数字键盘上方加入「完成」用于单手收起键盘；内容仍原样交给已有的金额/精度/成本安全校验。
- **营业表压缩布局**：营业位置与实际营业时间位于同一行；微信/支付宝/现金三列继续同排，多收款人分别显示小计和合计。没有填写营业时间时显示“实际时间未填”，不把其误判为某营业时段。
- **采购表压缩布局**：商品选择与移除置于同一行；数量、单价、单品小计同一行，可直接看到随输入更新的金额；单位/每件重量维持单独一行、历史有效进价可点击填入。保留全部已关联计划商品的锁定与防重逻辑。
- **原业务规则不变**：采购数量默认 1、单价默认 0、重量默认 0；单价 0 不改写历史有效进价；整单“总价”不是单品进价。营业利润预览复用现有计算，不新建 iOS 资金结算算法。
- **安全测试**：新增输入默认值、商品精度、收款人身份、金额有效性的回归测试。不会因为键盘或 UI 调整改动已上传订单、利润、凌晨收款或正式账本。
- **测试权限**：已实现功能仍集中在 iOS_TEST_ 测试账本工作台并接受服务端逐笔验证；库存、资金结算、客户账单等未实现的写入功能继续明确预留，不绕过接口。

## 安装
TrollStore 下载 TianXianFruit-iOS-v0.6.2-Build39-TrollStore，解压后覆盖安装 iPhone X / iOS 16.6 上的旧版。请勿卸载 App，以免丢失原有本机草稿、原子操作锁和缓存。本次不要求服务端升级。
