# 天鲜账本 iOS V0.6.8 · Build 45 — 结算断点恢复与跨设备核对

## 本版更新
- **无需重新生成核对单**：测试账本工作台直接显示保存的结算操作；重启、断网后可点击「恢复原操作 / 查询同步结果」，按原 UUID 查询服务端。
- **跨设备回读识别**：区分尚未同步、按原回执核对、其他设备后续覆盖、同版本金额异常；新版不会把安卓随后修改误认为原操作未成功。
- **防重复写入**：确认完成的旧操作 UUID 也禁止再次提交；只有前一次完整核对后才允许创建使用不同 UUID 的下一笔。
- **持久锁损坏保护**：读取失败时禁止新资金操作，不删锁、不换 UUID、不自动重发。
- **专项测试**：覆盖原操作身份重放、重启恢复所需锁、云端同步延迟、安卓新版本覆盖、金额不符与删除。
- **保持限制**：服务端 V1.0.31 仅允许 `iOS_TEST_` 测试账本原子修改已保存 DAILY 转账；正式账本仍只读；不更改安卓结算算法或 UI。
- **暂不开放**：日结重新生成、周期结清、利润分配写入、累计资金余额权威计算。

## 安装
GitHub Actions 下载 `TianXianFruit-iOS-v0.6.8-Build45-TrollStore`，解压后使用 TrollStore **覆盖安装**，不可卸载重装，以保留本机结算操作锁和草稿。
