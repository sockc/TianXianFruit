# 天鲜账本 iOS V0.3.1 — 测试采购备注更正与营业云端复核

适用 iPhone X / iOS 16.6 / TrollStore（最低 iOS 15）。版本 **0.3.1 / Build 16**，Bundle ID 维持不变。请使用 TrollStore **覆盖安装，不要卸载旧版**，以保留本机草稿、上传任务及独立测试账号 Keychain 会话。

## 本次更新

- 新增「采购 → 订单 → 修改测试账本采购备注」入口。**只允许 iOS_TEST_ 独立测试账本**和经验证的普通 USER 单账本测试账号，正式账本所有业务仍只读。
- 只允许修改一张已同步采购父订单的 **remark 备注（最多 200 字）**；不修改商品数量、单价、整单金额、采购人、采购状态、库存、客户或资金结算，避免父子表非原子更新。
- 在每次更正前完整读取测试账本，要求父订单具有唯一云端数字 ID，采购子项必须正确关联父订单且商品合计与订单金额完全一致。保留原采购的商品、金额与稳定同步 ID，并在同一记录基础上使用 `row_version + 1`。
- 提交前在线核实账号权限、原订单完整快照、所有商品明细及版本。将旧快照、新快照、商品快照及本机提交状态保存到独立 SQLite **之后**才允许发出一次网络请求。超时、断网或服务器冲突后禁止盲目重传，只允许只读核对。未发出的本机更正可安全取消。
- 服务器确认后再次只读回读订单及商品全部明细，核对版本和备注，确保金额/商品不被修改才提示成功。
- 在「更多 → 测试账本营业金额更正」的任务卡片上新增 **云端版本复核状态**：旧版本、已匹配、被其他设备继续更改、或金额归属异常；新增只读完整刷新入口。此功能仅证明当前云端状态，**不能证明 Android 本机已下载**。
- 新增采购编辑和营业云端审计专项回归，保留已有测试采购上传、营业新增/更正、只读报表与客户分析能力。

## 简化验收

iPhone X 直接覆盖安装 IPA。在独立 `iOS_TEST_` 测试账本进入采购详情，找到金额一致的现有测试订单，点击「修改测试账本采购备注」，例如填「已核对」，提交一次即可。安卓测试账号同步后查看该订单备注是否一致；如网络中断，只点「只读核对云端」，**不需要重输账号、密码和 ID，也不要再次发送同一任务**。

营业更正可在「更多 → 测试账本营业金额更正」查看云端版本核对结果，并通过只读完整刷新更新状态；安卓本机同步仍由安卓端执行。

## 风险与限制

本版只修改 iOS 测试分支、自动测试及打包工作流，不修改安卓 APP、正式服务器或原有「当日结算」计算逻辑与 UI。后端实际的事务级 CAS、行级写入权限和完整跨设备冲突仲裁尚未独立验证；客户端比较云端版本不等于服务器原子事务保证。**本版本禁止对正式经营数据试写**，只可使用不含真实账本数据的独立测试账号与账本。GitHub 自动测试通过不等于 Android 与 iOS 真机互认已完成。
