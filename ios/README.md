# 天鲜账本 iOS V1.0.1 · Build 78 — 安卓 UI 对齐第一阶段

- 首页、库存、采购、营业、结算共享经营日期；中国时区、中文星期、左右滑动、整月日历及确认。未来采购日期仍可选择，切到其他经营表回到不晚于今天；更换账本或退出重置工作日期。编辑器保留原独立日期及未保存保护。
- 首页四宫格（营业额/采购金额/实际利润/预估利润），使用原库存经营分析口径；天气移到核心操作下方，历史七天随日期变化。
- 采购计划默认展开，压缩金额与状态；营业日期、标题与历史记录更紧凑，库存四摘要和五列卡片、损耗与剩余快速输入；结算模块入口前置。保留已有计算、云端写入限制、回读、草稿与自动保存。
- 仍保留原营业及采购编辑弹层、采购总价只读计算；待下一阶段完成内嵌录入与安全验收。未引入未支持的凌晨收款、账单导入、利润规则写入。
- 独立候选 IPA 构建，不自动发布正式联合 Release，不改变 Android 或服务器。iPhone X 实机布局待核对。
