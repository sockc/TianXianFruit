# 天鲜账本 iOS V0.7.0 · Build 47 — 安卓式界面精简

## 本版更新
- **底部与安卓一致**：首页、库存、采购、营业、结算、更多，6 项固定原生风格导航，不再因超过5项而自动出现系统溢出菜单。
- **首页更紧凑**：安卓式 4列×2行快捷操作、统一的今日营业/采购/已存利润卡片、近7天与近30天营业汇总、7天每日数据。
- **账本栏精简**：账本切换、当前同步状态、一键刷新保持同一行；仅在测试账本显示小号“测试”提示，去除大块测试状态横幅。
- **营业页面**：日期选择、位置及营业录入优先；历史范围与搜索折叠到“筛选与历史”，减少顶部空间占用。
- **更多页面**：只保留经营统计、客户分析、采购历史、天气提醒、资金余额与结算记录、生成报表及折叠的账号/同步管理。不再展示测试工作台、旧版测试工具、未实现的功能预留及重复的库存入口。
- **当日结算**：从独立“结算”标签进入，测试账本直接显示“办理当日结算”。操作选项只展示真正已实现的部分结算、全额结算、恢复未结；技术 UUID/版本信息折叠，原操作的幂等与恢复保护不变。Build46 的只读诊断模型仍保留，但不占用正常结算页。
- **只读状态提示**：减少无意义的“只读”“云端记录”“服务器接口”常驻说明；正式账本仍然严格只读。
- **本机草稿保护**：iOS 不更改 Android 当日结算算法；不删除本地草稿、结算操作锁或同步数据；历史测试工具逻辑仍留在内部以保证升级安全，但不提供日常入口。
- **测试**：新增底部六栏顺序、功能图标、正式账本写入隔离、未开放结算项保护与静态 UI 守卫。

## 安装
GitHub Actions 下载 `TianXianFruit-iOS-v0.7.0-Build47-TrollStore`，解压后用 TrollStore **覆盖安装**，不可先卸载旧版本，以保留账本缓存、草稿和原子资金结算操作锁。

## 范围说明
这是 UI/可用性重构，不等于已在 iOS 实现安卓所有业务模块。库存结转、凌晨收款写入、利润分配、跨日结清等功能暂未开放写入，后端仍使用已部署的 V1.0.31，无需更新服务端。
