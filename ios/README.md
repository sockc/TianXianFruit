# 天鲜账本 iOS V0.4.0 — 采购主页面对齐安卓

**V0.4.0 / Build 20**。iPhone X、iOS 16.6、TrollStore 可覆盖安装（最低 iOS 15），**不要卸载旧版**。Bundle ID 不变，原有已验证登录、云端缓存和旧测试草稿均不迁移、不清理。

## 当前版本实际完成

- iOS **采购 Tab 不再是单纯的 30 天历史订单列表**，改成以 Android `CollaborativePurchaseUi.kt` 为布局依据的采购工作台：日期左右切换、月历日期选择、刷新、四项指标「计划金额／已完成金额／已采购／剩余」、待采购、按采购人分组的已完成采购，以及正式采购订单明细和采购历史入口。
- 云端采购计划严格按 Android 原始关系 `purchase_plan(plan_date)`、`purchase_plan_item(plan_id)`、`purchase_collaboration(plan_item_sync_id)` 关联；已完成正式订单使用 `purchase_order(sync_id)` 验证。**不同设备数字 ID 重复时停止错误关联，未拉取到的协作金额不作为 0 元。** 旧取消状态和已删除明细不参与汇总。
- 对已有正式账本账号（采购可编辑权限）开放**本机多商品采购录入**：采购日期、采购人、计划/临时采购、最多 30 种商品、数量、单位、每件重量、单价、商品小计、整单金额、采购备注。支持编辑、删除、跨日期查看。草稿按账号和账本独立存储于应用 SQLite，不需要第二套测试账号或反复填写账本 ID。
- **UI 清理**：正式账本的「更多」页面不再展示此前的五个测试实验室入口。旧测试账本仍有折叠的兼容工具，不影响既有测试提交数据；正式采购从底部「采购」进入。
- 采购历史保留原近 7 天／30 天／全部时间筛选、按采购人搜索、日期分组和云端商品金额核对。
- 自动测试覆盖安卓计划/协作/正式订单关联、重复父 ID 拦截、缺少金额不误报 0、取消/删除过滤，以及正式账号草稿的跨账号跨账本隔离、金额和采购人有效性。

## 重要：当前版本的云端写入边界

**V0.4.0 可以用正式账本查看采购计划、实际采购和历史，也能在正式账号下创建及管理本机采购录入；但新增草稿尚不能提交到正式云端。** 本机录入不能算作已经完成采购，且不会影响 Android 库存、采购成本、利润分配或结算。

原因是安卓「完成采购」会联合更新 `purchase_plan_item`、`purchase_collaboration`、`purchase_order`、`purchase_item` 以及相关经营派生数据。当前 iOS 的旧测试上传只具有单张表/按单个商品的操作与回读保证；没有正式服务端**原子多表提交、版本冲突和权限处理**，因此不能把它直接套到生产账本。需要先为正式采购完成建立服务端事务级接口或等价安全保障，才可开放 iOS 云端提交、采购完成/恢复、编辑删除。

**本版不改 Android、服务端、原有当日结算计算或 UI。** 此处无需用户逐项重复验收；GitHub 持续构建与自动回归继续保留。后续按**采购写入 → 营业 → 资金结算**顺序逐步完善。

## 安装和体验

1. 使用 TrollStore 对现有 iOS 版本**覆盖安装**。
2. 用现有正式账号登录，底部点击「采购」。左右切日，直接查看云端待采购、已完成采购及按采购人分组的记录。
3. 点击「＋ 添加商品／采购录入」，选择采购人与商品，录入数量和单价并保存。草稿显示为「本机采购录入 · 未提交」；其金额不会被并入正式已完成采购或结算。
