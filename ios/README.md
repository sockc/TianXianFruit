# 天鲜账本 iOS V0.6.4 · Build 41 — 安卓结算功能第一阶段

## 本版本新增
- **安卓原始结算状态**：读取 daily_cash_settlement.status 的 0（原始未结算）、2（原始部分结算）、1（原始已结算），缺少字段不再误判为未结算，未知状态保留待核对提示。日期卡片和展开后的日结快照都能查看对应状态。
- **当日转账逐笔登记**：按原始 settlement_transfer 中的方案金额及 settled_amount 显示未登记、部分登记、全额登记或金额异常，同时分别显示实际云端已登记金额；不自动确认转账或更新余额。
- **周期/历史转账分组**：当日 DAILY 方案与周期、资金中心、历史转账分开展示，保留记录日期及覆盖营业日期。支持 CUTOFF_CENTER 与 CUTOFF_LEGACY_INVALID 的正确分类；安卓标记为无效的旧版历史转账显著提醒。
- **跨日结清提示**：读取完整云端转账快照，寻找后续确认且已登记金额的 CUTOFF / CUTOFF_CENTER，按日期范围提示“可能覆盖本日”。不会把这一证据直接变成已结清状态，也不会将周期款重复计入当日金额。
- **原始数据异常识别**：超出方案金额、负数等异常登记值标注需核对；旧版记录有已登记金额但确认时间缺失时给予提示。不存在自动修正金额、自动四舍五入或重发结算。
- **安全回归**：专项单元测试涵盖原始状态 0/1/2、缺字段、未登记/部分/全部登记、异常金额、后续跨日记录、历史无效记录、同步墓碑删除。

## 重要边界
**原始状态 ≠ 安卓实时有效状态**：安卓还会根据当前资金中心、当日转账和跨日累计结清重新判断有效状态及资金余额。Build 41 只能基于已同步字段展示原始状态和逐笔登记证据，不能宣称真正的最终“已结清”。下一阶段再实现服务端/安卓有效状态与资金余额契约，避免 iOS 重算导致错账。

本版不改 Android 当日结算算法，不新增资金结算 POST/PUT/PATCH/DELETE，不允许 iOS 直接操作正式资金；现有 iOS_TEST_ 安全测试写入权限、采购/营业原子接口与原有草稿全部保留。

## TrollStore 安装
在 GitHub Actions 下载 TianXianFruit-iOS-v0.6.4-Build41-TrollStore，解压后通过 TrollStore 覆盖安装现有 iOS App（iPhone X / iOS 16.6）。勿先卸载，以免丢失本地草稿和操作锁。无需升级正式服务器。
