# 天鲜账本 iOS V0.8.4 · Build 53 — 日常账务与双端核对

本版基于 V0.8.3 Build 52，重点改善实际营业和采购使用体验、安卓跨设备数据变化核对、历史日期以及结算明细入口。没有新增测试菜单、自动写入或生产资金结算功能。

## 营业：正式账本安全状态与操作效率
- 营业页日期下直接显示云端最近拉取状态；有错误、离线缓存时提示并可手动刷新。
- 本机曾确认上传成功的营业，若当前已同步云端找不到原记录，或记录值不再符合原操作回执，显示删除/修改警告并提供只读重新核对入口；**不清空不可变操作、不创建第二笔营业**。
- 保留 V0.8.3 同日期同位置防重复、本机草稿存档、必填金额和时间提示；保留按位置筛选后自动带入新增营业的功能。

## 采购：金额、历史有效单价与云端复核
- 更换商品时旧商品的采购单价归零，避免误带到另一个商品；保留原本已录入的数量与重量，不自动用历史价格替换真实采购价。
- 查看历史有效单价时，只引用**所选采购日期及以前**的相同商品、相同单位的真实正进价；零价、跨单位、跨日期或无法唯一关联采购单的数据不可自动作为建议。
- 继续支持点击“填入”历史单价，由用户确认，而不是静默覆盖。
- 已确认的本机采购若云端订单、商品明细或关联计划被安卓修改，显示明显的待核对提示；点击“核对云端”时按原提交回执逐项核验，**不会再次 POST**。
- 采购页直接展示云端拉取状态和手动刷新；保留采购计划与正式订单金额分开呈现。

## 历史：可按指定日期快速定位
- 采购历史增加与营业表一致的日期切换入口，可按“单日、近7天、近30天、近90天、全部”查看；所有筛选均以所选日期为截止日期。
- 支持采购人及日期关键词同时过滤，不改变采购自然日成本归属。
- 点击记录仍使用云端原始订单与商品明细，不把未上传本机草稿当成已采购。

## 结算：保留安卓原始保存数值
- 每个有记录的日期卡片优先显示已保存的少量合伙人利润分配与**本日资金差额**，其余展开查看原记录。
- 不把本日轧差误称为跨日余额；不推断已结清；继续保留原始日结快照、采购、资金轧差、转账方案和周期结清提示。
- **生产正式账本资金结算继续只读**。没有改变安卓已有资金计算逻辑、利润分配或转账规则。

## 安全与部署
- 正式账本营业、采购仍由已部署 V1.0.32 的账本 UUID、操作人 UUID 白名单及各功能开关保护。服务端不自动开启生产写入，也不修改 Android 正式数据。
- 新增单元测试覆盖历史单价与日期筛选、已确认营业被删除或变更后的提示。
- Github Actions 构建 `TianXianFruit-iOS-v0.8.4-Build53-TrollStore`。iPhone X/iOS 16.6 使用 TrollStore **覆盖安装**；不要卸载旧版，避免本机草稿和不可变原操作锁丢失。
- 原生编译与模拟器单元测试应全部通过后才能认定为可安装发布；生产跨设备验收仍需实际设备验证。
