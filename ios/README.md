# 天鲜账本 iOS V0.6.1 · Build 38 — 安卓式输入体验与测试入口优化

## 本版更新
- **营业表输入**：微信/支付宝/现金三列同排，金额右对齐并使用数字键盘；一位收款人只需一组输入，多位收款人保留各人小计和汇总，不把多个收款人金额错误归属到一个人。
- **实时收款摘要**：汇总微信、支付宝、现金与当日收款总额，严格复用原有分单位金额解析。无效金额不擅自当作零；利润预览继续走原有 BusinessDraftWorkflowPolicy，不改真实结算。
- **日期与营业时间**：新增营业表、采购录入表统一左右切日与点击日历；实际营业时间及备注折叠显示，已填写的时间仍显示在营业位置下方；支持跨午夜 HH:mm 文本，不改变凌晨收款规则。
- **采购输入**：商品数量与已录入金额更清晰，维持安卓同样的采购人、计划关联、数量、单价、单位、每件重量及整单总额口径。待采购实际完成仍用既有服务端原子提交，保持防重、断网查询原操作和安卓回读。
- **测试工作台**：「采购备注更正」现在直接显示已同步订单供选择，再进入原有独立测试账号安全更正页面，减少绕路；保留现有营业更正、采购、营业和全部功能预留入口。
- **回归**：新增单人/多人收款金额展示、无效金额不能默认为 0、账号与测试账本隔离的专项测试。

## 权限与边界
- iOS_TEST_ 账本的已实现功能继续集中展示；实际写入仍按服务器在线能力、账户角色和原子事务校验。
- 库存、利润分配、资金结算操作、凌晨收款、客户导入、账本管理仍为明确的预留入口，**没有伪造写入能力**。
- 正式账本保持只读；Android 当日结算金额、计算逻辑、转账规则及全部正式数据没有更改。

## 安装
从 GitHub Actions 下载 TianXianFruit-iOS-v0.6.1-Build38-TrollStore，解压后使用 TrollStore 覆盖安装。不要卸载现有 App，避免丢失本地草稿与不可变上传锁。无需服务器升级。
