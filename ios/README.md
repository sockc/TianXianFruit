# 天鲜账本 iOS V0.6.9 · Build 46 — 资金对账检查

## 本版更新
- **新增只读资金对账检查**：资金结算页增加「资金对账检查」，支持近7天、近30天、全部日期范围，展示已保存 DAILY 当日转账的方案、累计已登记和未登记金额，以及逐日核对进度。
- **精确来源关联**：依据云端 `daily_cash_settlement` 与 `settlement_transfer` 的 Android 64 位原始 ID、关联字段及版本；未通过核对的记录不计入可靠合计。
- **异常定位**：提示重复日结、孤立当日转账、64位原始ID不匹配、登记超额、金额小数异常、原始日结状态和转账进度不一致、旧版无效资金转账。
- **防止误认资金余额**：周期结清与历史转账单独计数，不混入当日方案合计；日结已登记金额不代表实际银行到账。安卓资金累计余额需要已清断点、历史业务明细、有效利润和资金中心关系，**此版不声称能重新计算它**。
- **自动单测**：新增日期范围、精确64位ID、孤立/重复源记录、金额超额及小数位、周期转账防重复计算、原始状态不一致等回归。
- **写入限制**：服务端 V1.0.31 无需升级。原 Build45 的 iOS_TEST_ 原子日结转账写入及幂等锁原样保留；正式账本只读，不改变 Android 当日结算流程。
- **未开放**：资金中心权威累计余额接口、生成日结、利润分配写入、周期结清写入。

## 安装
从 GitHub Actions 下载 `TianXianFruit-iOS-v0.6.9-Build46-TrollStore`，解压后用 TrollStore **覆盖安装**。请勿卸载旧版，避免删除此前结算操作锁与本机采购/营业草稿。
