# 天鲜账本 iOS V0.5.4 · Build 36 — 资金结算表明细增强

## 当前版本更新
- **合伙人实际资金明细**：读取 Android 已同步的 settlement_partner，逐日按合伙人显示实际收款、采购垫付、费用垫付、已保存利润份额、应留存款和本日资金差额；默认折叠，不重新计算利润或余额。
- **同期经营与结算**：保留多位置营业明细和采购日归属；正式日结快照显示原始营业额、采购金额、其他费用和利润；缺失时标记，不能以本机汇总代替。
- **分配详情**：显示已保存利润分配以及原始 ratio 和角色字段，比例不随意乘以 100。
- **转账类型及覆盖期间**：区别 DAILY / CUTOFF / CENTER / LEGACY，读取 range_start_date、range_end_date、business_day_count，避免将跨日结算误认成某天新增转账；缺少周期字段时不臆测日期。
- **筛选完整性**：合伙人过滤涵盖资金日结明细、利润分配和转账记录。正式日结快照与采购成本保持全账本，不按位置/合伙人猜测归属。
- **安全与回归**：同步记录被删除后不能回流；没有日结快照不推算当日结算或“已结清”；Android 当日结算、资金轧差算法与正式账本任何数据均未修改。

## 安装
TrollStore 请覆盖安装 Build 36，不要卸载已有应用；适用于 iPhone X / iOS 16.6。GitHub Actions 生成测试 IPA；本版不要求服务端升级，也不影响 Build 34 的 iOS_TEST_ 采购写入能力。

## 已知边界
本版只显示 sync/pull 中实际返回的数据，不保证生产同步服务器一定已推送所有 settlement_partner 记录；缺少记录时会出现提示。不会把本日资金差额解释成跨日累计余额，转账的“已登记结算”不等于银行实际到账。若需要完全复刻 Android 资金余额计算和最少转账弹窗，须先验证完整的服务端资金结算数据契约，再独立开发。
