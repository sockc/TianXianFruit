# 天鲜账本 iOS V0.7.1 · Build 48 — 营业客流联动

## 本版更新
- **营业记录新增「客流 ›」**：单日和历史营业列表，位置名称右侧、营业额左侧直接进入对应日期的客户分析。
- **严格位置关联**：仅从营业记录 `store_sync_id` 或精确 Android 64位 `store_id` 唯一对应已有云端位置时自动选择对应摊位。未知、重复或来源冲突时只带入营业日期，提示未能确定归属；绝不根据位置名称、收款金额、或收款人猜测。
- **日期操作更像安卓**：客流页采用与营业表相同的左右切日和整月日期选择；顶部只保留日期、渠道、核心指标，范围和位置筛选默认收起，减少小屏幕占用。
- **同位置同星期逐小时对比**：在客户分析里折叠查看“时段 / 本次付款笔数 / 历史日均 / 差额”，与已有逐小时柱形统计互补，历史至少2个有导入记录的同星期日才显示。
- **数据准确性**：微信、支付宝合并或单独切换；历史无导入记录的日期绝不补零；多个营业位置共用收款人时仅依据云端账单原有归属，并提示用户核对。
- **回归测试**：新增7项营业-客户位置映射用例、2项逐小时对比用例，覆盖64位ID不失真、相同名称歧义、位置关联冲突、无账单日期与历史样本不足。
- **保留安全边界**：不修改安卓当日结算、成本与库存计算、不增加任何资金或客户写入路由、不清除本机草稿及原子操作锁。正式账本继续只读，测试账本写入仍受 V1.0.31 原有权限与幂等保护。
