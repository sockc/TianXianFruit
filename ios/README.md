# 天鲜账本 iOS V0.2.8 — 测试账本采购双端核对

适用 iPhone X / iOS 16.6 / TrollStore（最低 iOS 15）。版本 **0.2.8 / build 13**，Bundle ID \`com.tianxian.fruit.ios\` 不变。**覆盖安装，不要卸载旧版**；保留本机草稿、Keychain 会话及已开始的上传队列。

## 本次更新

- **Android → iOS 云端采购明细**：在「采购」列表点某张订单，读取当前账本缓存的全部 \`purchase_item\`，显示商品名称、数量、单位、单价及金额。
- **父子关联安全**：采用服务器订单实际数字 \`id\` 关联商品 \`order_id\`；父订单 ID 缺失、重复或变更时不猜测归属，明确提示。
- **金额核对**：按分累计已读取商品金额，与订单保存总价比对。区分「云端一致」「存在差额」「商品未同步或字段不全」「父订单冲突」四种状态。
- **详情刷新**：点击「刷新云端采购」使用原有只读增量拉取，失败不会清空旧缓存或改动草稿。
- **专项测试**：三商品 ¥240、部分商品、错误父 ID、缺金额及删除、数字 ID 冲突。

## 原有功能保持

iOS V0.2.7 的测试专用账号自动登录、单账本权限核验、多商品本机采购草稿、一键上传 \`iOS_TEST_\` 账本、逐条商品出网前落盘及异常只读回读逻辑均保留。不会自动重发结果不确定的订单或商品。

**正式账本仍只读**。不修改 Android 工程、服务器、凌晨收款、资金转账及当日结算的计算逻辑与 UI。

## 简化验证

在 Android 的同一个 \`iOS_TEST_\` 测试账本保存并同步一张包含多种商品的采购单。iPhone 点右上角刷新，再从「采购」打开对应订单即可核对商品和总价。若仍显示差额或明细缺失，先让 Android 完成同步，再刷新 iOS，不要重复上传原单。

本版本的 GitHub 自动测试不等同于 Android/iOS 真实双机端到端验证。
