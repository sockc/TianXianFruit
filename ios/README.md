# 天鲜账本 iOS V0.5.0 / Build 32

本版把已经通过双端同步验证的营业新增和更正流程调整为更适合每日使用的操作界面；不涉及服务端部署或 Android 当日结算算法。

## 本版更新（仅列当前版本）

- **营业页本机待处理列表**按实际出网状态显示：尚未上传、原操作结果未知、服务端已接收待回读、云端已有同日同位置记录；确认回读成功的本机草稿不再被标成“未上传”。
- 点击待处理的某个位置，直接打开该日期、该位置的草稿；单一收款人时默认选中该收款人。
- **重新进入已经保存的草稿**，会识别它确实已保存，不用无意义地再按一次保存。
- 保存以后若继续改微信/支付宝/现金、支出、开摊/收摊库存或备注，上传按钮立即禁用，直到把最新表单保存。**不会悄悄提交上一次保存的金额**。
- 填写收款及库存成本依据后，实时显示按现有 Android 营业公式得到的营业额和利润预览；未填的成本项保持空白，不擅自当成 0。
- 已有同日同位置云端营业时阻止新增，并可直接进入云端明细；不会生成重复记录。

## 安全范围与安装

测试账本（名称以 `iOS_TEST_` 开头）可继续使用 V1.0.29 的专用营业原子提交以及现有安全更正。正式账本营业新增仍只保存本机草稿，营业更正保持只读；未开放跨账本通用 `/sync/push`。本版不修改结算、凌晨收款、利润分配、资金转账、采购成本规则。

TrollStore 对 iPhone X（iOS 16.6）**覆盖安装** Build 32，不要卸载旧版，以保留本机草稿与原操作保护记录。无需重新登录服务器或升级服务器。

自动化测试可验证功能规则，但仍不能替代真实设备上最终账单核对；在测试账本仅需按正常经营方式录入/更正，不再要求重复逐项测试。

相关限制：`PRODUCTION_BUSINESS_READINESS.md`、`BUSINESS_COMMIT_CONTRACT.md`。
