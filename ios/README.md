# 天鲜账本 iOS V0.8.6 · Build 55 — 最近 7 个实际营业日／采购日

本版按 Android 正式页面的现有历史展示规则开发，**取消新增“单日账务核对中心”**。直接在营业表、采购表下方显示云端历史，兼顾录入和核对。

## 营业表底部 · 最近 7 个营业日
- 所选日期已有记录仍在页面上方展示；下方新增“营业历史 › 最近7个营业日”。
- 与 Android 一致：只计算所选日期**之前**有实际营业记录的 **7 个不同日期**，而非最近七个自然日。
- 同一天多位置按日期分组，显示位置数量、当日营业额合计、各位置营业额及云端已有微信／支付宝／现金金额。
- 点击位置查看原始营业明细；客流仍走现有入口。点“营业历史 ›”切换完整历史筛选。
- 选择日期后列表随日期切换；不把本机草稿、未来记录或所选当天重复计入七日历史。

## 采购表底部 · 当天 + 之前 7 个采购日
- 保留所选日期的采购订单和采购计划；**当天订单不占前七日名额**。
- 在当日订单下方新增“采购历史 › 当天 + 前7个采购日”，只显示之前有实际采购订单的 7 个不同日期。
- 按日期显示订单数、采购金额合计，并列出每笔采购人、原订单金额。点订单查看云端商品明细及金额核对。
- 未完成计划和仅本机录入的草稿不计入已采购历史；选择不同日期自动更新列表。
- 点击“采购历史 ›”可进入现有日期／采购人筛选的完整采购历史。

## 安全与兼容
- 该功能只查询 `ReadOnlySnapshot` 的 Android 云端原始营业和采购数据，**不会发出修改、删除、写入或自动结算请求**。
- 原有营业／采购上传、正式账本白名单、不可变 outbox、跨设备同步、成本、利润分配和转账规则全部保留。
- 自动测试覆盖：七个实际日期、多位置及多订单分组、跳过空白自然日、排除当天和未来、选择日期变化。
- iPhone X/iOS 16.6 使用 TrollStore **覆盖安装**；继续保留上一版 App 图标和深色顶部修复。
- 目标安装包：`TianXianFruit-iOS-v0.8.6-Build55-TrollStore`。GitHub Actions 模拟器测试、设备 IPA 和资源验证全通过后才算构建成功。
