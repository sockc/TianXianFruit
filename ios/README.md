# 天鲜账本 iOS V0.3.2 — 测试同步统一核对中心

版本 **0.3.2 / Build 17**。适用 iPhone X、iOS 16.6、TrollStore（最低 iOS 15）。仍使用原 Bundle ID，**请直接覆盖安装，不要卸载旧版**；本机测试草稿、同步任务与 Keychain 会话保留。

## 本次更新

- 新增「更多 → 测试同步核对中心」，统一显示当前独立 `iOS_TEST_` 测试账本上的四类**本机提交任务**：采购新增、营业新增、营业金额更正、采购备注更正。点击进入后优先恢复既有专用测试账号，不反复要求输入账号、密码或账本 ID。
- 一次联网验证账号权限、完整拉取云端最新记录（包含删除墓碑），同时核对四类任务。新中心**只有读取、没有 POST、不会重发任何任务，也不会改变本机上传状态**。
- 区分「本机尚未发送」「云端当前一致」「云端有后续版本」「云端未找到」「云端已删除」「同版本字段不符」「账号范围不匹配」。后续版本不再直接拿最初的提交金额作错误比较，防止把正常的安卓后续修改判为同步失败。
- 顶部四项统计「总任务、已匹配、后续变化、需核对」，可筛选问题、全部、已匹配和后续变化；任务显示本机状态、云端状态及具体说明。
- 采购新增采用现有采购父/子订单回读审计，营业新增核对收入及收款人，营业/采购更正分别核对新版本的金额、利润或备注与对应明细。不声称可以远程证明 Android 本机已经下载了新版本。
- 专项回归覆盖从未发送但云端同值、后续版本、同版本金额变化、删除墓碑、不同测试账号身份、采购/营业更正与四种任务的汇总。
- 修正专用测试设备登录向服务端报告的 `app_version` 为 `0.3.2`。此前 V0.3.1 的采购备注修改、营业金额更正、多商品上传和既有报表均保留。

## 最少验收流程

在 iPhone X 用 TrollStore 覆盖安装后，打开 `iOS_TEST_` 独立测试账本，进入 **「更多 → 测试同步核对中心」**。以前登录过专用测试账号的，可以自动恢复并完成一次只读核对；看一下有无「需核对」即可。若要核实 Android 是否已接收到更改，仍需在安卓端切换到同一个测试账本执行同步，本中心仅检查服务端，不向 Android 发送确认请求。

## 安全说明

本版只改 iOS 测试分支和构建/测试流程，不修改 Android 正式版本、服务端、凌晨收款、资金结算或当日结算计算及 UI。**正式账本始终只读**。正式后端的事务级 CAS 及行级隔离尚未独立审计；此前的任何写入能力都只允许测试账本验证，不允许对真实经营数据试写。GitHub XCTest 通过不等于双机真机验收。
