# 天鲜账本 iOS V0.8.2 · Build 51 — 正式账本写入准入协议

## 营业与采购

- iOS 仅在服务端对当前账本提供完整原子提交能力及 **scope=formal** 时，才开放正式账本营业与采购云端提交。
- V1.0.31 及之前未返回 scope 的服务器**只能用于 iOS_TEST_ 测试账本**。正式账本继续允许保存本机草稿，但不得发送云端写入。
- 每次提交前重新检查当前账本、操作人、服务端权限和完整同步状态；沿用不可变操作编号、防重、事务行版本及逐项回读。
- 测试账本已有业务流程保持不变，原操作待核对时不创建另一笔重复提交。
- 采购草稿保存后仍需明确确认云端提交。

## 服务端依赖

必须使用单独提供的 **TianXian Server V1.0.32** 服务端授权协议，且由服务端基于 UUID 白名单独立审批。仅安装 IPA 或升级服务端并不会默认开启正式写入。
服务端的新正式权限默认关闭，且要求账本 UUID、操作人 UUID、各业务模块开关及原有权限全部匹配。

## 结算保留原有规则

此版**不开放正式账本资金结算写入**，不生成日结方案，不重算分红、现金轧差或最少转账规则。安卓现有结算数据不受影响。正式资金结算须另行核对跨日资金依赖后才能准入。

## 安装

GitHub Actions 成功后下载 `TianXianFruit-iOS-v0.8.2-Build51-TrollStore`，在 iPhone X / iOS 16.6 使用 TrollStore **覆盖安装**；不要卸载原有应用，否则本机未上传草稿可能丢失。
