# 天鲜账本 iOS V0.8.1 · Build 50 — 营业草稿可靠性与结算日期

## 本版修复

- **营业先录入、后补成本**：允许只填写部分收款或成本就保存本机草稿。未填完不计入云端营业或利润；只有真实收款、逐人收款人和全部成本通过安卓兼容校验后才显示“保存并同步营业”。
- **切换日期、位置防丢数据**：有未保存的金额、备注或库存时，弹出“先保存在本机、放弃修改、继续编辑”三选项。切换不会静默覆盖输入。
- **营业草稿存储保护**：按账号和账本读取历史本机数据。原数据格式错误或不能解码时禁止用空数组重写，已有完整草稿在更新前保留一个备份，并对新写入进行回读核对。
- **结算日期直达**：从所选日期的结算页进入“办理已保存转账”时保持当前日期，不再每次回到今天。继续仅处理已经同步、可以核对的服务端日结方案。
- **版本升级**：V0.8.1 / Build 50，保留 iOS 15+ 与 TrollStore 无开发者证书构建。

## 未改变的边界

正式账本营业与采购仍不能通过当前服务端安全接口写入；本机草稿不是云端记录。
结算只针对已保存转账数据，不生成全新日结、周期结清或利润分配；Android 当日结算公式及转账规则原样保留。
不修改服务端、正式账本历史、账号权限、原子操作 ID 和同步游标。

## 安装

GitHub Actions `Build TrollStore IPA` 成功后下载 `TianXianFruit-iOS-v0.8.1-Build50-TrollStore`。
iPhone X / iOS 16.6 通过 TrollStore **覆盖安装，勿卸载原版**，以保留本机草稿及已锁定的操作记录。
